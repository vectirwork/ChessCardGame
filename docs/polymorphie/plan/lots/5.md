## Étapes
1. layout.ts : fanT, fanPose (r = 7t, y = 14t²), fanArrival (28t), oppFanSpan(n) ((90n+27)/100 jusqu'à 3, puis (70n+47)/100), handCardWidth(n, l, vw, vh) et oppCardWidth(l, vw, n) exportées. OPP_FAN_SPAN, DESKTOP_OPP_ROOM, gameLayout et desktopHandRight inchangés.
2. GameShell :
   - FAN[i % 3] et [-28, 0, 28] remplacés par ces fonctions ;
   - N déduit des mains ;
   - pour N > 3 seulement, data-crowd et variables en ligne avec de nouvelles règles CSS ;
   - un seul écouteur de redimensionnement (useGameLayout) ; écouteur clavier stable.
3. Salle d'attente : prop emptyHand ; « Partie sans cartes » seulement sans cartes.
4. CardDraft :
   - textes par fr.ts et regles.ts (choixComplet, choisissezVos, accords pour 1) ;
   - barre de temps depuis view.draft.totalMs (repli sur DEAL.draftMs) ;
   - GamePage.process transmet l'événement reveal ; la note de révélation s'affiche si `you ∈ filled` (repli sur l'heuristique actuelle si filled manque) ;
   - message d'expiration selon la sélection ;
   - verrou 500 ms avant l'échéance locale ; la validation envoie aussitôt la sélection ;
   - colonnes de la réserve, révélation selon N, donne k·n + i, raccourcis jusqu'à 9, cartes exclues calculées (liste()).
   Décisions pures extraites en fonctions testables.
5. GamePage :
   - consignes par regles.ts ;
   - émotes : un minuteur par couleur, annulé à chaque émote, à la revanche et au démontage ; key sur la bulle ;
   - incrément barré si noIncrement ; « L'IA joue pour X » si standIn ;
   - numérotation depuis fullmove ; railTop dérivé.
6. shell/cards.ts :
   - castsThisTurn (liste) ;
   - apresLancement(r, annonce, reste) ;
   - handNotes teste les codes de refus, avec un repli transitoire sur le texte, retiré au lot 9.
7. SpellCard : pastilles par cardEndsTurn(def, rulesOf(state)). CardHand se fie à cardPlayable seul. CardBack reçoit un id SVG unique (prêt pour un futur dos de carte).
8. overlays et parts :
   - JoinSheet par regles.ts ; carte de fin conditionnée par useFeature('ranked') ;
   - seuil du compte à rebours du premier coup dérivé de l'échéance ;
   - GUEST_NAME ; tcLabel ;
   - formatClock avec heures (identique pour les cadences actuelles) ;
   - « deux fois plus vite » depuis rate ;
   - retrait de levelName.
9. game.css : .pl-levels en repeat(var(--n, 3), …).
