## Étapes
1. Page blanche :
   - PageBoundary, avec pour clé le chemin, autour de <Suspense> ; « Réessayer » recrée le composant paresseux (page() garde un lazy recréable après un rejet) ;
   - createRoot(…, { onUncaughtError }).
2. api.ts : délai maximal par AbortSignal.timeout ; échec réseau transformé en ApiError(« Connexion au serveur impossible. Vérifiez votre réseau. », 0) ; errMsg ne relaie que les ApiError.
3. store.tsx :
   - refresh avec nouveaux essais espacés ; état « inconnu » distinct de « invité » ;
   - logout avec finally setMe(null) ;
   - useFeature (meta, puis /api/me).
4. socket.ts : emitAck typé sur ClientToServer ; constantes SOCKET explicites (valeurs par défaut de socket.io) ; auth.v envoyé ; sur server:outdated, rechargement avec la garde d'une minute.
5. main.tsx : vite:preloadError ne recharge que pour le code d'une page ; un module facultatif (three.js) ne recharge plus la page.
6. ROUTES (métadonnées), utilisées par :
   - App, qui filtre selon les interrupteurs, avec des import() littéraux et un Record exhaustif, donc le même découpage en morceaux ;
   - Layout (menus, grilles --n) ;
   - NotFound ;
   - robots.txt.
7. site.ts :
   - meta sm-features injectée seulement si une valeur diffère des défauts ;
   - canonical, og:url et og:image absolus depuis PUBLIC_URL (changement invisible) ;
   - titre initial égal à celui que la page pose déjà ;
   - statut 404 pour un chemin inconnu ;
   - cookie sm_guest posé aussi sur les réponses HTML.
   Tout est calculé une fois par page.
8. Marque :
   - Layout et un useTitle unique lisent BRAND ;
   - greffon Vite (transformIndexHtml, y compris en développement) avec des marqueurs dans index.html, manifeste émis par generateBundle, sortie identique octet pour octet ;
   - le même greffon appelle checkRules et fait échouer le build en cas d'erreur.
9. Legal : état d'erreur réseau avec « Réessayer » ; liste des produits depuis SLOT_LABEL seulement après Q5 (texte inchangé sinon).
10. storage.ts : usePref réécrit sur useStored, par KEYS (valeurs inchangées).
11. global.css : retrait des classes mortes (.spacer, .grid-3, .gradient-text, .hairline, .btn-arcane, .divider, .auth-wrap) après une recherche finale.
12. og.tsx : textes dérivés ; image non régénérée sans Q5.

## Tests

- marque.test.ts : dist/client/index.html et manifeste identiques octet pour octet (noms de fichiers hachés normalisés).
- socle-client.test.ts : PageBoundary (rejet de chargement, puis « Réessayer » ; exception de rendu) ; repli réseau en français ; meta absente au défaut ; useFeature.
- checkRules qui échoue fait échouer le build.
