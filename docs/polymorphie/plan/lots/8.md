## Étapes
1. Textes chiffrés par regles.ts dans Rules, Play, Learn, Puzzles et lessons.ts (§4.2, §4.3). Pluriels corrigés : Learn:65 et 82, MyGames:162.
2. Rules :
   - frise de la Trêve générée depuis coups (6 étapes au défaut) ;
   - grilles .rg-* en repeat(var(--n, valeur actuelle)) ;
   - note humanOnly/timedOnly composée d'après les drapeaux ;
   - phrase du Sablier exclu calculée ;
   - phrase R9 par limitesMain ;
   - « Les échecs, tels quels » inchangé.
3. Play : BOT_LEVELS, DEFAULT_BOT_LEVEL, DEFAULT_QUICK, descriptions des niveaux, portes filtrées par useFeature, GUEST_NAME, --n sur .pl-levels.
4. Leçons et problèmes :
   - créés avec { rules: RULES_V1 } ;
   - champ requires ({ handsVisible, cardsPerTurn: 1, cardBefore: true }) qui masque ce qui contredit les règles courantes ;
   - hand([...]) tronque à la taille courante (carte de la solution en tête) ;
   - gabarits (maxMoves, coups, rangées) ;
   - problème du jour stable (date d'ajout, `since`) ;
   - filtres générés depuis THEME_LABEL.
5. Libellés uniques : tcLabel, catalogLabel (repli unique), modeLabel, colorName, romain() ; copies de format.ts, MyGames, Live, Profile (lecture seule) et Analysis supprimées.
6. history.ts enregistre `rules` ; Analysis rejoue avec rulesOf (createGame avec rules).
7. Supprimer SkinPreview (Home.tsx) et DemoBoard.tsx, désormais sans usage (concepts sorti de la vérification) ; CSS mort de pages.css (Jouer et Règles « conservées », SkinPreview).
